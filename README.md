# tokenbyte 帮助文档

欢迎使用 tokenbyte！本文档包含软件的快速上手指南、核心配置说明以及常见问题解答。

---

## 📖 快速开始

### 1. 环境准备
在使用 tokenbyte 之前，请确保你已满足以下要求：
* 操作系统：Windows / macOS / Linux
* 浏览器：Google Chrome / Edge / FireFox
* 开发工具：Python / Node.js / cURL

---

## ⚙️ 使用说明

### 1. 创建账号
前往 https://tokenbyte.ai/ 创建账号, 支持邮箱、GitHub、Discord 以及通行密钥（Passkey）登录。

### 2. 创建 API Key
登录后 进入控制台 -> API 密钥管理，点击 新建 API 密钥（建议为每个应用或环境单独创建一个 Key，并配置合适的速率限制）。

### 3. 发起请求
3. TokenByte 的基础 URL 是 https://api.tokenbyte.ai/v1。所有示例中的 model 请替换为你在 模型广场 或 控制台 -> 模型市场 看到的模型ID。

## ❓ 常见问题 (FAQ)

**Q: 遇到报错该怎么办？**
A: 请检查网络连接以及配置文件中的 Key 是否正确。

**Q: 如何联系支持？**
A: 可以提交 Issue 或发送邮件至 support@tokenbyte.ai。
