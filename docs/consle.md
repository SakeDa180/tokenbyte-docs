# 控制台指南

---

## 登录与导航

使用邮箱密码、第三方 OAuth 或通行密钥登录后，你会看到顶部导航：

* **仪表盘** — 本月用量总览、成本趋势与近期调用日志
* **API 密钥** — API Key 的创建、编辑与吊销
* **模型** — 可用模型列表、服务商与单价
* **日志** — 按请求粒度查询历史调用
* **任务** — 图像、音频等异步任务的状态
* **钱包** — 余额、充值记录与发票
* **个人资料** — 账户信息、密码与通行密钥

---

## API 密钥管理

### 1. 新建 API 密钥

进入 **API 密钥** 页面，点击 **新建 API 密钥**。可配置：

* **名称** — 用于区分用途，例如 `production-web`、`staging-ci`
* **过期时间** — 可选，到期后自动失效
* **数量** — 可选，默认为 1，可以创建多个密钥，名称将以 `名称-` 开头
* **单次消费上限** — 防止异常调用造成的意外花费
* **模型白名单** — 留空表示允许全部模型；建议生产环境限定必要的几个
* **IP 白名单** — 留空表示允许所有 IP 地址；建议生产环境限定必要的 IP 地址

### 2. 复制并妥善保存

创建完成后请立即复制并妥善保存密钥，系统将不会再次完整显示。

### 3. 批量操作

勾选多行后可进行批量吊销或导出。批量查询 Key 元数据可使用后台的批量 API。

## 用量与日志

**日志** 页面记录每次 API 调用的请求/响应摘要、消耗 Token、命中模型与耗时。可按 API 密钥、模型、时间区间筛选。

> **说明**：日志默认保留 1 年。
