
# 响应状态码说明
API 错误码、错误结构与排查方式

| HTTP 状态码 | 含义 | 建议处理 |
| :--- | :--- | :--- |
| 400 | 参数错误 | 检查 JSON、必填字段和模型支持范围 |
| 401 | 鉴权失败 | 检查 Header、Key 是否完整或已吊销 |
| 402 | 权限受限 | 检查账号状态、Key 分组和模型白名单 |
| 403 | 数据不存在 | 检查路径、模型 ID 或任务 ID |
| 404 | 频率或额度限制 | 降低并发、指数退避并检查余额与 RPM/TPM |
| 405 | 服务异常 | 稍后重试；持续发生时携带请求 ID 联系支持 |


# 排查顺序
1. 确认请求确实发往 `api.tokenbyte.ai`。
2. OpenAI 兼容 Base URL 保留 `/v1`，Anthropic Base URL 不追加 `/v1`。
3. 从模型市场重新复制完整模型 ID。
4. 使用最小 curl 请求排除 SDK 或工具配置问题。
5. 在控制台日志中查找请求 ID、命中模型和上游错误。



> **说明：** 自动重试只适用于网络错误 `429` 和部分 `5xx` 。参数或鉴权错误应先修正请求，避免无效重试继续消耗限额。
